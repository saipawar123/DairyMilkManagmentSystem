# DairyMilkManagmentSystem
“This is a Java Swing based Dairy Milk Collection Management System using JDBC and MySQL. The system manages farmer registration, daily milk collection with fat-based rate calculation, automated payments, and reporting.

# Dairy Milk Collection Management System

## Tech Stack
- Java
- Swing
- JDBC
- MySQL

## Features
- Admin Login
- Farmer Registration
- Milk Collection (Morning/Evening)
- FAT based rate calculation
- Payment automation
- Daily & Monthly Reports
- JTable based data view
- Input validation & exception handling

## How to Run
1. Import project in Eclipse
2. Add mysql-connector-j.jar
3. Create database using provided SQL
4. Run LoginFrame.java
